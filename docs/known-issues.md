# Known Issues

Open problems, gaps and cleanup for the ThinkTwice rebuild. Add new issues here as they're found, and remove them (in the same commit as the fix) once they're resolved.

_Last updated: 2026-10-22._

**Priority:** P1 = blocks the next milestone, P2 = needed before release, P3 = nice to have.

## Open

| #   | Priority | Area       | Issue                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| --- | -------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | P1       | Release    | **Existing users' data must be migrated before the rebuild goes live.** The live version has active users whose data is in Cloud SQL (`thinktwice-dev-christion:us-central1:thinktwice`) in the old schema. Before replacing it: back it up, write and test a one-time migration into the new tables (matching users by Firebase UID), and rehearse it on a copy. Nobody may lose data.                                                                                                                                                                                 |
| 2   | P2       | Branding   | **The logo needs new source files.** `docs/brand/app-logo.png` is 512×512 with its own cream, slightly blurred square background, which shows as a visible box in the app (especially in dark mode). Needed: a transparent-background version for in-app use, a 1024×1024 app store icon (ideally from a vector SVG), and an Android adaptive icon with the artwork inside the safe zone.                                                                                                                                                                               |
| 3   | P2       | Deployment | **API hosting is undecided.** `api.thinktwice.site` has no host chosen yet. The previous version runs on Cloud Run (`us-east4`) in the same Google Cloud project, which is the natural candidate. Needed before release.                                                                                                                                                                                                                                                                                                                                                |
| 4   | P2       | API        | **Deleting a Firebase account isn't designed yet.** Account deletion must also delete the user's Firebase sign-in account. Without `firebase-admin`, either the app deletes it with the Firebase JS SDK (`deleteUser`) after the API deletes the data, or the API calls Firebase's REST API with a service account. Decide when building account deletion.                                                                                                                                                                                                              |
| 5   | P2       | App        | **Expo is one patch behind on purpose.** The app uses Expo SDK 58.0.16 because 58.0.17 was released less than a day before setup, inside pnpm's minimum release age. 58.0.16's tooling includes the deprecated `uuid@7.0.3` (via `@expo/config-plugins` → `xcode`, build tooling only). Once 58.0.17 is a day old (after about 2026-10-22 18:00 UTC), run `pnpm --filter @thinktwice/mobile exec expo install --fix` confirm `uuid@7.0.3` is gone, and remove `GHSA-w5hq-g745-h8pq` from `auditConfig.ignoreGhsas` in `pnpm-workspace.yaml`.                            |
| 6   | P2       | Security   | **Four reviewed vulnerabilities are ignored by the dependency audit.** All are in development-only tools, never in the app, API or ML service: `uuid` (Expo CLI, fixed by the Expo upgrade above), `node-forge` (Expo CLI's local HTTPS certificates), `braces` (Metro's file watcher, fed only our own patterns) and `sprintf-js` (Jest coverage). The last three have no fixed release yet. Each is listed by advisory ID in `auditConfig.ignoreGhsas` in `pnpm-workspace.yaml`; remove each one as soon as a fix ships. Any new vulnerability still fails the audit. |
| 7   | P3       | Tooling    | **TypeScript 7 isn't supported yet.** The repo uses TypeScript 6.0 because typescript-eslint (and Expo SDK 58's template) only support TypeScript below 6.1. Upgrade once typescript-eslint supports TypeScript 7.                                                                                                                                                                                                                                                                                                                                                      |
| 8   | P3       | Setup      | **Node.js on the dev machine is one patch behind.** It has 24.21.0; the latest Node 24 LTS release is 24.22.1. Update with `winget upgrade OpenJS.NodeJS.LTS`, then update the version in `docs/setup.md`.                                                                                                                                                                                                                                                                                                                                                              |
| 9   | P3       | API        | **Graceful shutdown hasn't been verified yet.** `services/api/src/server.ts` closes the server on SIGINT/SIGTERM, but Windows (Git Bash) can't send a real SIGTERM, so it's only been tested by force-stopping. Verify it once the API runs in Docker (when it's added to `compose.yaml`).                                                                                                                                                                                                                                                                              |
| 10  | P3       | App        | **Jest's own dependencies include deprecated packages.** `glob@7` and `glob@10`, `inflight` and `whatwg-encoding` come from Jest 30, React Native's Jest preset and jsdom. They're test tools only and never ship in the app, and there's no non-deprecated way to test React Native yet (Christion chose the official setup). Dependabot will bring fixes when Jest updates them.                                                                                                                                                                                      |
| 11  | P3       | App        | **`eslint-plugin-react` doesn't support ESLint 10 yet**, so the app is linted with `eslint-plugin-react-hooks` (rules of hooks and React Compiler checks) plus strict TypeScript, without `eslint-plugin-react` or `eslint-config-expo`. Add them once they support ESLint 10.                                                                                                                                                                                                                                                                                          |

## Notes

These aren't to-dos; they're facts worth knowing.

- **`main` still holds the previous version of the app.** The rebuild lives on `christion`. The first pull request from `christion` into `main` will replace the old code entirely, so only open it once the rebuild is ready to take over. The old code stays in `main`'s git history.
- **The previous version is live at thinktwice.site.** Don't deploy over it until the rebuild is ready (see `CLAUDE.md`).
- **Only Claude's commits are pushed automatically.** Commits made by hand need a manual `git push` (see the Git workflow note in `CLAUDE.md`).
- **Claude's personal memory isn't in the repo** and is lost on a computer reset. Everything important from it is recorded in `CLAUDE.md`.
